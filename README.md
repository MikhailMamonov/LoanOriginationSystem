# LoanOriginationSystem
Backend-система для автоматизации процесса выдачи кредитов физическим лицам. Она собирает, валидирует и структурирует данные о заёмщике (анкеты, место работы, доходы), подготавливая их для передачи в скоринговую систему, которая принимает решение — одобрить кредит или отказать.
Проще говоря: это "цифровая анкета + конвейер данных", через который проходит каждый клиент банка или МФО перед тем, как получить кредит.
